# 🎮 Mini Game Hub

A **Single Page Mini Game Hub** built using **Vanilla JavaScript, HTML, and CSS**.  
This project demonstrates modular frontend architecture, dynamic loading, and clean UI design — all without using any frameworks.

---

## 🚀 Live Demo

👉 **Play the games here:**  
https://rkvankini.github.io/mini-game-hub/

> (Hosted using **GitHub Pages**)

---

## 🧠 Games Included

### 🧠 Memory Game
- Easy (4×4) & Hard (6×6) modes
- Timer ⏱️
- Move counter
- Smooth flip animations
- Responsive square tiles
- Restart option

### ⚡ Reaction Speed Game
- Test your reaction time
- Random delay challenge
- Instant result feedback

*(More games coming soon 🚧)*

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (Flexbox, Grid, Animations)
- **Vanilla JavaScript**
- No frameworks, no libraries
